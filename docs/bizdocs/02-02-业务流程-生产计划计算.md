## 02-02 业务流程清单 – 生产计划计算域

> **范围**：月度生产计划的自动计算、结果审核、人工调整、多版本管理。  
> **说明**：每个流程用 `PP-FLOW-xxx` 编码，角色遵循 RASIC（R=Responsible, A=Accountable, S=Support, I=Informed, C=Consulted）。

---

### PP-FLOW-001 月度生产计划计算

- **目标**：基于完成品预测、BOM、物料参数和库存数据，自动计算多期多层生产计划数量，为生产排程、采购计划、能力人时规划提供基础数据。
- **涉及角色**：生产计划员（R）、计划主管（A）、生产部长（C）、财务（I）
- **前置条件**：预测、BOM、物料参数、稼动天数、盘点数等基础数据已完成导入和冻结
- **后置结果**：生成完整的生产计划结果集（结果表），包含每个物料每月的计划生产数量、是否需要生产的判断、库存递推情况
- **标准流程**：
  1. **检查基础数据完整性（生产计划员）**
     - 逐一检查：预测数据是否冻结、BOM 是否完整（无断链）、物料参数是否齐全、稼动天数是否维护、盘点数是否生效；
     - 若发现数据缺失或异常，通知相应负责人补全后再进行计算；
     - 特别关注新产品或新工序，确保 BOM 数据已更新。
  2. **触发生产计划计算（生产计划员）**
     - 登录 APS 系统，进入"生产计划计算"功能；
     - 输入计算参数：计划开始期间（YYYYMM）、计划截止期间（YYYYMM）、是否覆盖历史计划（覆盖/追加）；
     - 点击"开始计算"触发后台计算任务。
  3. **系统执行多期多层 BOM 展开（系统自动）**
     - 系统按预置的 BOM 结构进行递推展开：
       - 第 1 步：取完成品预测数量作为第 1 层需求；
       - 第 2 步：遍历每个完成品的 BOM，推导第 2 层子件需求 = 完成品计划数 × BOM 用量；
       - 第 3~N 步：逐层展开至原材料级别；
     - 对于多工序产品，BOM 中每行记录的工序信息会在结果集中保留，便于后续能力规划。
  4. **系统执行库存递推计算（系统自动）**
     - 按月份逐期递推库存变化：
       - 期初库存 = 上期期末库存（或第 1 期使用盘点数）；
       - 期末库存 = 期初库存 + 计划生产量 × (1 - 报废率) - 期间需求；
       - 下期期初库存 = 本期期末库存。
  5. **系统计算计划生产数量（系统自动）**
     - 对每个物料每期，采用公式计算：
       - **计划数量 = (需求 / 稼动天数 × 安全天数 + 需求 - 当前库存) / (1 - 报废率)**
       - 其中：需求 = 该期汇总所有上层产品对该物料的需求；
       - 当前库存 = 期初库存；
       - 安全天数、报废率来自物料参数；
       - 稼动天数来自该月维护的稼动天数。
     - 计算结果若为负数，则置为 0（无需生产）。
  6. **系统自动判断是否需要生产（系统自动）**
     - 对每个物料每期，判断逻辑：
       - 若 需求 > 当前库存，则"是否要生产" = Y；
       - 否则"是否要生产" = N（库存充足，暂不生产）。
  7. **计算完成，生成结果集（系统自动）**
     - 系统生成结果表，字段包括：完成品编码、存货编码、年月、工序、设备、模腔数、制造周期、持台人数、单件节拍、当前库存、预测、库存天数、稼动天数、报废率、是否要生产(Y/N)、计划数量；
     - 结果集自动保存，标记版本号和计算时间戳，便于后续追溯和对比。
  8. **计算异常处理（系统自动 / 计划主管）**
     - 若计算过程中发生异常（如 BOM 循环、数据类型错误、计算超时），系统记录异常日志；
     - 计划员查看异常日志，定位问题原因（通常是基础数据错误），修正数据后重新计算。
- **关键业务约束**：
  - 计划数量公式中的报废率必须以小数形式输入（如 3% = 0.03），否则计算结果严重偏离；
  - 计划开始期间必须晚于最后一个盘点期间，否则期初库存无法正确确定；
  - 安全库存天数设置过高会导致计划数量大幅增加、库存积压；设置过低会导致库存风险提高，需与生产和成本团队平衡；
  - 多次计划计算若选择"追加"模式，需注意不要重复计算同一期间，建议定期备份和清理历史版本。

### PP-FLOW-002 计划结果审核与导出

- **目标**：对生成的生产计划进行多维度查询、验证、人工微调，并导出供下游采购、生产排程、能力规划等环节使用。
- **涉及角色**：生产计划员（R）、计划主管（A）、生产部长（C）、采购部（I）
- **前置条件**：生产计划已计算完成并保存
- **后置结果**：确认无误的计划版本被冻结并发布；计划数据导出至 Excel 或下游系统
- **标准流程**：
  1. **计划结果初步查看（生产计划员）**
     - 登录 APS 系统，进入"计划结果查询"功能；
     - 查看计划生成的统计信息：计算期间、物料总数、计划生产量汇总、报表预览；
     - 识别明显异常（如某物料计划数量特别大或特别小，应进一步核查）。
  2. **多维度过滤与查询（生产计划员）**
     - 支持按以下维度过滤、查询和导出结果：
       - 按期间（月份或期间范围）；
       - 按完成品编码；
       - 按物料编码；
       - 按工序名称；
       - 按设备编码；
       - 按是否需要生产（Y/N）；
       - 自由组合多个过滤条件。
  3. **识别关键物料和瓶颈（生产计划员）**
     - 按"是否要生产 = Y"过滤，识别本期需要生产的物料清单；
     - 按计划数量从大到小排序，识别量大的关键物料（影响资源分配的物料）；
     - 为后续采购计划和能力规划提供重点关注清单。
  4. **人工微调计划数量（生产计划员）**
     - 对于某些特殊情况（如存在特殊订单、需要临时加单、库存清理等），允许人工单条调整计划数量；
     - 在结果查询界面选中某条记录，点击"编辑"，修改"计划数量"字段，系统自动重新计算期末库存；
     - 修改后的记录标记为"已调整"，便于追溯和审计。
  5. **计划版本对比（计划主管）**
     - 若存在多个计划版本（如多次计算的版本），支持版本对比功能；
     - 对比维度：期间、物料、计划数量变化、库存变化等；
     - 通过对比可以评估不同版本的差异影响（如采购成本、库存水位）。
  6. **计划审核与签字（计划主管）**
     - 计划主管与生产部长、采购部等相关方审核计划内容：
       - 验证计划数量的合理性（是否符合市场预期、库存政策）；
       - 识别库存高峰期和低谷期，评估存储成本和缺货风险；
       - 确认生产节奏是否均衡，避免大幅波动。
     - 审核通过后，计划主管在系统中勾选"已审核"，冻结该版本。
  7. **计划导出与分发（生产计划员）**
     - 冻结的计划版本可导出为 Excel，包含结果表的全部字段；
     - 也可导出为 CSV 或其他格式，供采购、生产排程、能力规划等系统导入；
     - 系统自动记录导出时间和导出人员，便于追溯。
  8. **计划发布与生效（计划主管）**
     - 计划导出后，计划主管在 APS 中正式发布该版本，标记为"生效"状态；
     - 生效后，采购部、生产部、能力规划团队可基于该版本制定下游计划；
     - 直到下一期新计划发布前，该版本保持生效。
- **关键业务约束**：
  - 一旦计划冻结并发布，如需调整需重新计算并走审核流程，不允许直接修改已生效版本；
  - 人工调整计划数量会改变库存递推结果，需谨慎操作并补充调整说明（如"临时加单+500套"）；
  - 导出的 Excel 不应作为最终归档版本，应保留 APS 系统内的计算版本记录；
  - 若发现计划有误（如计算错误或基础数据错误导致的计划失准），需立即通知全部下游部门重新规划。
