## 02-01 业务流程清单 – 基础数据管理域

> **范围**：预测、BOM、物料参数、稼动天数、盘点数的导入、维护与校验。  
> **说明**：每个流程用 `MD-FLOW-xxx` 编码，角色遵循 RASIC（R=Responsible, A=Accountable, S=Support, I=Informed, C=Consulted）。

---

### MD-FLOW-001 预测数据导入与维护

- **目标**：确保 APS 系统中完成品月度预测数据完整准确，为后续 BOM 展开和生产计划计算提供唯一输入源。
- **涉及角色**：需求规划工程师（R）、计划主管（A）、物流部（I）
- **前置条件**：销售部已生成月度完成品预测数据；APS 系统已初始化
- **后置结果**：APS 中存储完整的完成品预测数据库，可供生产计划计算使用
- **标准流程**：
  1. **收集销售预测数据（需求规划工程师）**
     - 从销售系统或需求计划系统导出完成品月度预测数据，包含：存货编码、年月（YYYYMM）、预测数量；
     - 预测仅适用于完成品级别，子件需求由 BOM 展开推导。
  2. **准备预测导入模板（需求规划工程师）**
     - 将预测数据整理成 APS 预测导入模板格式（Excel）；
     - 模板包含列：存货编码、年月、预测数量、删除重写标记；
     - 删除重写标记用于区分新增/修改（"N"）还是删除覆盖（"Y"）。
  3. **批量导入预测数据（需求规划工程师）**
     - 在 APS 系统中选择"预测数据导入"功能，上传 Excel 模板；
     - 系统自动校验数据完整性（存货编码存在、年月格式正确、数量为正数）；
     - 若校验通过，批量保存到预测数据库；若失败，返回错误信息，工程师修正后重新导入。
  4. **单条新增/修改/删除（需求规划工程师）**
     - 对于需要单笔调整的预测，可在预测查询界面单条操作：新增、修改数量、删除记录。
  5. **预测查询与确认（计划主管）**
     - 计划主管登录系统查询预测数据，按存货编码和年月查看；
     - 确认预测数据完整无误后，冻结预测版本（标记为"生效"状态）。
  6. **生产计划员取用预测（生产计划员）**
     - 生产计划员触发生产计划计算时，系统自动引用已生效的预测数据。
- **关键业务约束**：
  - 预测数据仅维护完成品级别，子件需求严格通过 BOM 展开逻辑推导，不允许手工维护；
  - 删除重写标记一旦保存，历史版本的该条记录将被覆盖，建议定期备份预测数据；
  - 计划主管冻结预测后，需求规划工程师仍可修改，但需要主管再次确认生效。

### MD-FLOW-002 BOM 主数据维护

- **目标**：建立并维护完整的多层 BOM（物料清单）结构，确保生产计划计算和产能人时测算的精准性。
- **涉及角色**：工艺工程师（R）、生产计划主管（A）、物料工程师（S）
- **前置条件**：产品设计已完成，产品 BOM 架构已定义；工序流程已确定
- **后置结果**：APS 中存储完整的多层 BOM 库，可供计划计算和能力规划使用
- **标准流程**：
  1. **收集工艺 BOM 数据（工艺工程师）**
     - 从工艺系统或工艺档案中提取每个产品的完整 BOM 结构；
     - 每行 BOM 记录包含：父零件编码、子零件编码、用量、工序名称、设备编码、模腔数/取数、制造周期（秒）、持台人数、单件节拍（秒）；
     - 对于多工序产品，按工序顺序排列各子件消耗信息。
  2. **准备 BOM 导入模板（工艺工程师）**
     - 将 BOM 数据整理成 APS BOM 导入模板格式（Excel）；
     - 验证数据：父零件与子零件编码在系统中存在、用量为正数、工序和设备编码有效；
     - 制造周期和单件节拍采用秒为单位，便于后续设备负荷计算。
  3. **批量导入 BOM 数据（工艺工程师）**
     - 在 APS 系统中选择"BOM 导入"功能，上传 Excel 模板；
     - 系统自动校验父子零件关系、字段完整性和数据类型；
     - 校验通过则保存，失败则返回错误清单，工艺工程师修正后重新导入。
  4. **BOM 多层展开校验（生产计划主管）**
     - 在系统中执行"BOM 多层展开预览"功能，检查 BOM 结构的正确性；
     - 验证：完成品 → 半成品 → 原材料的展开路径无循环、无断链、叶子节点为可采购物料；
     - 若发现问题（如循环依赖、缺失子件），通知工艺工程师修正。
  5. **单条新增/修改/删除（工艺工程师）**
     - 对于新增工序或临时工艺变更，可在 BOM 查询界面单条操作：新增 BOM 行、修改参数（用量/工序/设备等）、删除行；
     - 修改后自动重新计算多层展开，供下次计划计算使用。
  6. **BOM 版本管理（生产计划主管）**
     - 定期（如产品设计变更时）冻结当前 BOM 版本，标记生效日期；
     - 新 BOM 版本与生效日期关联，计划计算时按生效日期自动选择相应版本。
- **关键业务约束**：
  - BOM 每行记录代表一道工序，同一子件多个工序消耗需分行记录；
  - 制造周期和单件节拍的单位必须统一为秒，不允许混用分钟或小时；
  - 模腔数/取数字段用于设备产能计算，必须与实际生产工艺一致；
  - 工艺变更时，需同时更新 BOM 和物料参数（如新增工序设备的持台人数），确保后续计划精准。

### MD-FLOW-003 物料参数维护（报废率/库存天数）

- **目标**：维护物料级别的报废率和库存天数参数，为生产计划计算提供补偿因子和库存约束。
- **涉及角色**：质量工程师（R，报废率）、库存管理员（R，库存天数）、计划主管（A）
- **前置条件**：所有物料编码已在系统中注册；生产历史数据已积累（用于报废率统计）
- **后置结果**：APS 中存储完整的物料参数库，供计划计算使用
- **标准流程**：
  1. **统计报废率（质量工程师）**
     - 从 SQE/品质系统导出各物料的历史报废数据（按时间段汇总）；
     - 报废率 = 报废数量 / 生产投入数量；通常按 3 个月或 6 个月滚动平均计算；
     - 将报废率整理成表单：物料编码、报废率（百分比）、统计期间。
  2. **新增/修改报废率（质量工程师）**
     - 在 APS 系统中选择"物料参数维护"，按物料编码查询或新增；
     - 输入该物料的报废率（如 3%），系统记录生效日期；
     - 对于某物料多次更新报废率，新版本自动覆盖旧版本（保留修改历史）。
  3. **统计库存天数需求（库存管理员）**
     - 根据库存管理政策和物流规划，确定各物料的安全库存天数（防止缺货的最少库存天数）；
     - 可参考物料供应周期、需求波动性、工厂的库存成本承受能力，一般设置 3~15 天；
     - 同时设定最大库存天数（如 45 天），防止库存积压。
  4. **新增/修改库存天数（库存管理员）**
     - 在 APS 系统中选择"库存天数维护"，按物料编码输入：安全天数、最大天数；
     - 安全天数用于生产计划计算中的库存下限约束；
     - 最大天数仅用于分析预警，不强制约束计划数量。
  5. **参数生效与冻结（计划主管）**
     - 计划主管查看参数维护历史，确认参数无误后冻结版本；
     - 冻结后的版本在规定期间内生效，供后续计划计算调用。
- **关键业务约束**：
  - 报废率必须基于真实生产数据统计，不允许凭估计设置；
  - 物料参数变更（如报废率提升、安全天数增加）可能导致计划数量大幅变化，需提前沟通生产和成本团队；
  - 对于进口物料或供应周期长的物料，安全库存天数应设置较高（如 20~30 天）；对于供应稳定的国内物料可设置较低（如 5~10 天）。

### MD-FLOW-004 稼动天数维护

- **目标**：维护每月实际生产稼动天数，用于生产计划计算中的需求日均转换。
- **涉及角色**：生产计划主管（R）、生产部长（C）
- **前置条件**：工厂全年节假日、停产计划已确定
- **后置结果**：APS 中存储各月稼动天数，计划计算时自动调用
- **标准流程**：
  1. **确定年度稼动日历（生产部长）**
     - 综合考虑国家法定节假日、工厂自定义停产日（如维保、换季）、周末休息，确定每月的实际生产工作天数；
     - 一般工厂月稼动天数为 20~22 天（考虑周六日和节假日）。
  2. **输入稼动天数（生产计划主管）**
     - 在 APS 系统中选择"稼动天数维护"，按年月输入；
     - 输入格式：年月（YYYYMM）、稼动天数（整数）；
     - 可批量导入年度稼动日历或逐月单条输入。
  3. **稼动天数确认（生产计划主管）**
     - 与生产部确认稼动天数数据，确保与生产日历一致；
     - 特殊情况（如临时停产、缩短生产周期）需及时更新。
  4. **生产计划计算调用（系统自动）**
     - 计划计算时，系统自动查询该月的稼动天数；
     - 用于计算日均需求：日均需求 = 月度需求 / 稼动天数。
- **关键业务约束**：
  - 稼动天数必须为正整数，通常范围 18~23 天；
  - 若中途发生非计划停产（如设备故障、安全事故），需及时更新该月稼动天数，并同时调整已生成的计划；
  - 不同工厂/车间可能有不同稼动日历，APS 需支持按工厂或工序维度配置（如需）。

### MD-FLOW-005 盘点数导入与维护

- **目标**：导入期末库存盘点数据，作为下一期生产计划计算的期初库存，确保库存约束的准确性。
- **涉及角色**：库存管理员（R）、计划主管（A）、财务（I）
- **前置条件**：月末实物盘点已完成；财务库存结账已确认
- **后置结果**：APS 中存储各期期末盘点数据，用于后续计划递推
- **标准流程**：
  1. **获取实物盘点数据（库存管理员）**
     - 从 WMS 或库存系统导出月末盘点结果；
     - 数据包含：存货编码、年月底（YYYYMM）、可用量（考虑待检、不良品等）。
  2. **准备盘点数导入模板（库存管理员）**
     - 将盘点数据整理成 APS 导入模板（Excel）；
     - 模板列：存货编码、年月、可用量、删除重写标记；
     - 删除重写标记用于处理盘点后有新增调整的情况。
  3. **批量导入盘点数（库存管理员）**
     - 在 APS 系统中选择"盘点数导入"，上传 Excel 模板；
     - 系统校验存货编码有效、数量为非负数、年月格式正确；
     - 校验通过则保存，供下期计划计算使用。
  4. **单条新增/修改/删除（库存管理员）**
     - 对于盘点后发现的少量调整（如新发现的库存或报废），可在盘点查询界面单条操作。
  5. **盘点数确认与冻结（计划主管）**
     - 计划主管与财务确认盘点数与财务库存结账一致；
     - 确认后冻结该月盘点数，标记为"已生效"，供计划计算调用。
- **关键业务约束**：
  - 盘点数必须与财务库存结账数据一致，否则生成的计划会与财务报表产生偏差；
  - 盘点数是分期库存递推的启动条件，必须完整（不允许有缺失的物料或期间）；
  - 若发现盘点数与实际严重偏离（差异 > 5%），需立即调查原因（盘点错误、中途损耗、未记录的出入库）并纠正。
