## 03-02 系统功能清单 – 生产计划计算域

> **范围**：生产计划计算、结果查询、数据导出、计划调整、版本管理的系统功能点。  
> **说明**：每个功能点用 `FUNC-PP-xxx` 编码。计算逻辑详见 `02-02-业务流程-生产计划计算.md`。

---

### FUNC-PP-001 生产计划计算触发

- **终端**：PC
- **所属模块**：生产计划 - 计划计算模块
- **支撑场景**：PP-FLOW-001 月度生产计划计算
- **主要输入**：
  - 计划起始月（YYYYMM）
  - 计划截止月（YYYYMM）
  - 各基础数据版本号：
    - 完成品入库需求数版本（按客户+版本号选择）
    - BOM 版本
    - 半成品安全库存版本
    - 半成品期末盘点数版本
  - 计算结果版本名称（用于标识本次计算输出）
- **主要输出**：
  - 计算任务提交确认（任务 ID）
  - 计算完成通知（成功/失败/警告）
  - 计算日志（包含跳过项、异常信息）
  - 生成的结果集版本号
- **核心计算步骤（系统自动执行）**：
  1. 按版本号读取各基础数据。
  2. 按月份循环，每月内：
     a. 遍历该版本完成品入库需求数，计算每个完成品的计划生产数 = 需求 ÷ (1 - 报废率)。
     b. 遍历 BOM，逐层推导半成品净需求与计划生产数（详见业务流程文档核心逻辑）。
     c. 同月同半成品：现存量逐步消耗；安全库存只加一次。
     d. 净需求 ≤ 0 时计划生产数 = 0，停止向下展开。
  3. 每月计算完成后写入结果集，并递推期末库存供下月使用。
- **约束/说明**：
  - 系统须在计算前校验：BOM 无循环引用；盘点数覆盖起始月前一个月；安全库存年月覆盖计划期间。
  - 计划期间建议不超过 24 个月。
  - 大规模计算为后台异步执行，支持进度查询和中止操作。

### FUNC-PP-002 生产计划结果列表查询

- **终端**：PC
- **所属模块**：生产计划 - 计划结果模块
- **支撑场景**：PP-FLOW-002 计划结果审核与导出
- **主要输入（查询条件）**：
  - 结果版本号（下拉选择，默认最新）
  - 年月范围（起止月）
  - 完成品编码
  - 自制件编码
  - 工序名称
  - 设备编码
  - 是否生产（计划生产数 > 0 / = 0）
- **主要输出（列表字段）**：

  | 字段 | 说明 |
  |------|------|
  | 工序 | BOM 工序 |
  | 设备 | BOM 设备 |
  | 自制件 | 物料编码 |
  | 自制件名称 | 由零件主数据表按 `itemCode` 关联得到 |
  | 自制件产品番号 | 由零件主数据表按 `itemCode` 关联得到 |
  | 自制件项目 | 由零件主数据表按 `itemCode` 关联得到 |
  | 完成品 | 顶层完成品编码 |
  | 完成品名称 | 由零件主数据表按 `finishedProductCode` 关联得到 |
  | 完成品产品番号 | 由零件主数据表按 `finishedProductCode` 关联得到 |
  | 完成品项目 | 由零件主数据表按 `finishedProductCode` 关联得到 |
  | 年月 | YYYYMM |
  | 需求 | 净需求数（扣库存加安全库存后） |
  | 生产 | 计划生产数 |
  | 模腔数/取数(pcs) | BOM 字段 |
  | 制造周期(S) | BOM 字段 |
  | 持台人数(人) | BOM 字段 |
  | 单件节拍(S) | BOM 字段 |
  | 报废率 | BOM 字段 |
  | 版本号 | 计算版本 |

- **约束/说明**：
  - 默认按完成品、自制件、年月升序排列。
  - 零件主数据扩展字段来自独立的零件主数据表，查询时动态关联；若主数据缺失，对应扩展字段返回空值，不影响计划结果主体查询。
  - 支持分页，单次查询响应时间 < 5 秒。

### FUNC-PP-003 生产计划结果导出

- **终端**：PC
- **所属模块**：生产计划 - 计划结果模块
- **主要输入**：
  - 导出范围（当前查询结果 / 指定版本全量）
  - 导出格式（Excel .xlsx / CSV）
  - 导出文件名（默认：APS_计划结果_版本号_导出日期.xlsx）
- **主要输出**：
  - 导出文件（下载链接）
  - 导出统计（行数、时间、操作人）
- **约束/说明**：
  - Excel 文件包含计划头信息（版本、计算日期、期间范围）。
  - 导出记录日志，便于追溯。

### FUNC-PP-004 生产计划数量手工调整

- **终端**：PC
- **所属模块**：生产计划 - 计划结果模块
- **主要输入**：
  - 选择要调整的结果记录
  - 新的计划生产数（非负整数）
  - 调整原因说明
- **主要输出**：
  - 调整成功/失败提示
  - 调整后的期末库存（自动重新递推）
  - 调整记录（审计用）
- **约束/说明**：
  - 只允许修改"计划生产数"字段，其他字段不可改。
  - 调整后自动重新递推该物料后续月份的期末库存。
  - 调整记录标记"已调整"状态，保留调整前后对比数据。
  - 仅允许对"草稿"或"编辑中"状态的版本调整；已冻结版本不可调整。

---

### FUNC-PP-005 多版本计划管理

- **终端**：PC
- **所属模块**：生产计划 - 版本管理模块
- **主要输入**：
  - 版本列表查询（按计划期间、计算日期、状态等过滤）
  - 版本操作（查看、复制、冻结、归档）
  - 版本对比（选两个版本对比差异）
- **主要输出**：
  - 版本列表（版本号、计划期间、计算日期、状态、行数）
  - 版本对比结果（差异行高亮：新增/删除/修改）
- **版本状态流转**：草稿 → 编辑中 → 已审核 → 已发布 → 已归档
- **约束/说明**：
  - 草稿状态可删除；已发布状态只可归档，不可删除。
  - 支持版本复制（基于已有版本创建新草稿）。
  - 所有版本保留计算日志，支持追溯重现。
